# One Letter: Coffee or Tea

An entry for the make.fun bounty "One Letter: Coffee or Tea".
`main.py` writes exactly one letter to `entry.txt` in the output
directory (`MAKEFUN_OUTPUT_DIR`, default `/output`): one character,
no newline, no punctuation, nothing else, as the gate requires.

The final content of `entry.txt` is:

```
A
```

A is for coffee: the first letter, the top grade, the letter that
starts things — for the drink that starts the day. Ten candidates
were drafted and weighed (see `CANDIDATES.md`); tea (B) won on
trueness in the first pass, but the judge weighs vividness first,
and on vividness coffee overwhelms: hot, bitter, bright, and
impossible to sleep through. Tea steeps; coffee strikes — so
the entry stands on a single, clean, unmistakable `A`.

Run it with: `python3 main.py`
